# Security & Privacy Policy

## Our Security & Privacy Model

**ClipBoardUltra** is built from the ground up to respect your privacy and protect sensitive data:

1. **100% On-Device Execution**: ClipBoardUltra contains **zero network requests, zero telemetry, and zero tracking code**. No copied data ever leaves your computer.
2. **Automatic Secret Detection**: ClipBoardUltra includes an automatic credential filter that detects API keys, JWT tokens, AWS credentials, SSH private keys, and passwords, giving you the option to exclude them from clipboard history.
3. **App Exclusions**: You can configure ClipBoardUltra to ignore clipboard changes from specific applications (e.g., 1Password, Bitwarden, KeePass, Terminal).
4. **Transient Pause Mode**: Quickly pause clipboard recording for 5 minutes, 1 hour, or until manually resumed with a single shortcut or menu bar toggle.
5. **No Sandboxing Vulnerability Overreach**: ClipBoardUltra requests only the **Accessibility** permission strictly required to simulate the `⌘V` keystroke into the active target application. It does not request Full Disk Access, Camera, or Microphone permissions.

## Reporting Security Concerns

If you discover a potential vulnerability or security issue within ClipBoardUltra, please do not open a public issue. Instead, report it responsibly:

- **Email**: Create a private GitHub Security Advisory at `https://github.com/sharooz007/ClipBoardUltra/security/advisories/new`
- You will receive a response within 48 hours.

Thank you for helping keep ClipBoardUltra secure!
